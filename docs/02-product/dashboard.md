# Admin Dashboard (Module 6)

One screen, whole-organisation view for the owner.

## Blocks
- **Counters:** open leads · running projects (Design vs Site Installation) · pending complaints · staff present today.
- **Staff activity:** per person — first activity, last activity, calls made, leads handled, proposals generated (today).
- **Alerts:** unseen proposals, seen-no-action, stagnant leads (from reminders).
- **Recent feed:** latest project posts/comments needing owner attention.

## Notes
Read-only aggregates over existing data; no custom report builder. Activity timestamps come from a lightweight activity log ([data-model](../03-architecture/data-model.md)).
