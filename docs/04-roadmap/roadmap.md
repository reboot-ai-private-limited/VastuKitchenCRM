# Roadmap (1–2 weeks)

Target: working demo in **10 working days**; days 11–14 are buffer. Stay shallow in every phase.

| Day | Focus | Deliverable |
|---|---|---|
| 0 | Docs & decisions (this) | Docs scaffold, scope locked |
| 1 | Foundation | Monorepo, shared package, API + Mongo, auth + role guard, Cloudinary upload, web shell + login |
| 2–3 | Leads + Proposals | Lead table (manual + CSV), pipeline, call/visit logs, proposal builder → PDF + public seen-tracked link, `wa.me` send |
| 4 | Reminders | Cron jobs, in-app notifications (+ FCM push if time) |
| 5–6 | Projects feed | Auto-convert on Won, feed with photos + comments, client/internal tab, design board, final delivery → closed |
| 7 | Complaints | Raise → assign → resolve with photo |
| 8 | HR | Employee add, simulated punches + GPS log, simple salary table |
| 9 | Dashboard + Mobile | Admin dashboard; RN app (sales, technician, customer); call-log tracking |
| 10 | Demo polish | Dummy data, deploy web (Vercel) + API, build APK, rehearse [demo script](../demo/demo-script.md) |
| 11–14 | Buffer | Fixes only |

## Cut order if slipping
1. Push notifications (keep in-app)
2. Design team board
3. Salary table
4. Optional extras (TODO, announcements)

Never cut: lead table, proposal + seen tracking, project feed, complaints, dashboard.
