# 06 - Server work the mobile app depends on

Status: draft for the mobile team, 2026-11-12. Scope: `apps/api`, `packages/contracts`, and the few `apps/web` places that must change with them. Nothing here is implemented yet.

How this list was built: every "API gap / GAP / UNVERIFIED" item in the research files was re-checked against the code. Items that turned out false are in section 0 (so nobody re-adds them); items the research missed are marked NEW. Evidence is `file:line` relative to `apps/api/src` unless it starts with `packages/` or `apps/web/`.

Legend. Size: S (under a day), M (1-3 days), L (a week or more). Priority: P0 blocks the first mobile release; P1 needed for a good release; P2 later. "Web fix" = the same change also repairs a bug on the web app today. Dependencies refer to IDs in this file.
